# CreditVista

**Division:** RallTheory Financial Services
**Chapters:** 4
**Stack:** Python Flask

## Description

CreditVista is an internal credit risk dashboard used by RallTheory Financial Services. It demonstrates traceability, quality metrics, and linking code changes to work items.

## Quick Start

```bash
cd RallTheoryGroup/src/financial-services/creditvista
pip install -r requirements.txt
python app.py
```
