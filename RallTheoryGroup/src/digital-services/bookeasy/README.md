# BookEasy

**Division:** RallTheory Digital Services
**Chapters:** 2, 3, 5, 6
**Stack:** Node.js + Express

## Description

BookEasy is an appointment booking platform used by RallTheory Digital Services. It serves as the primary application for learning source control, GitHub Flow, branching strategies, pull request workflows, and Azure Boards integration.

## Quick Start

```bash
cd RallTheoryGroup/src/digital-services/bookeasy
npm install
npm start
```
