# NotifyBridge

**Division:** RallTheory Digital Services
**Chapters:** 19
**Stack:** .NET Minimal API

## Description

NotifyBridge is a communication and notification API. It demonstrates alerts, notifications, and monitoring integration for a DevOps environment.

## Lab implementation

This directory currently contains a `src/.gitkeep` placeholder, not a .NET project or webhook receiver. Follow [Lab 19](../../../../ch19/ch19_Lab_Guide.md) to create the .NET 8 health host and monitor it with real Azure Monitor action groups and tested Teams Workflow/Slack integrations.

No `/notify` or `/webhook` endpoint is implemented here. The lab uses external notification integrations rather than pretending the application accepts those payloads. Build, deployment, delivery, gating and suppression evidence remain **VALIDATION REQUIRED** until executed in the reader's sandbox.
