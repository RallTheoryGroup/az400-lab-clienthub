# RallTheory Group

## Parent Company

**RallTheory Group**

- Domain: `ralltheory.com` (or `ralltheory.local` for internal examples)
- Entra ID tenant: `ralltheory.onmicrosoft.com`

### Company Description

RallTheory Group is a fictional technology-led holding company with multiple business divisions across finance, digital services, software products, and managed IT operations. The company uses Azure, GitHub, and Azure DevOps to modernize delivery, automate infrastructure, improve software quality, and support secure enterprise operations.
